# Guía editorial de SoyCurioso

## Forma de una curiosidad

Cada curiosidad debe ser breve, visual y fácil de leer:

1. Título con gancho.
2. Resumen de una frase.
3. Imagen protagonista.
4. Desarrollo de 3-6 párrafos.
5. Categoría principal.
6. Etiquetas concretas.
7. Fuente o referencia.

## Categorías iniciales

- Ciencia
- Naturaleza
- Historia
- Filosofía
- Misterio
- True Crime
- Tecnología
- Psicología
- Cultura
- Enigmas
